## ❓ FAQ

**Do I need to run it as Administrator?**
Yes — admin rights are required for the tool to attach and manage client-side assets.

**Will my antivirus flag the file?**
Some engines flag game tools by heuristic. Add the folder to exclusions if needed. League of Legends uses Vanguard, a kernel-level anti-cheat, and Riot actively monitors for third-party tools; this package does not claim to be undetectable.

**Does it work on Windows 11?**
Yes — Windows 10 and Windows 11 (64-bit) are supported.

**Does it work in ranked and normal games?**
Cosmetic changes are applied client-side; Riot's terms of service still apply, and account action is possible. The tool does not provide any gameplay advantage.

**How do I update?**
Download the latest archive and replace the old files — saved loadouts and favorites are preserved.
